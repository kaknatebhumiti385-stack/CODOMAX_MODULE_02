# Codomax Module 02 – Task 2

## Project Title
AWS Security and Least Privilege Policy Testing

## Objective
To understand AWS security and the principle of least privilege using Python and JSON.

## Technologies Used
- Python
- JSON
- Visual Studio Code

## Project Description
This project simulates AWS IAM permission checking using a JSON policy file.

It demonstrates:
1. Allowing S3 object read access.
2. Allowing S3 bucket listing.
3. Explicitly denying object deletion.
4. Denying unauthorized upload access.

## Security Concepts
- IAM Policies
- Least Privilege
- Explicit Deny
- Default Deny
- Access Control

## Execution
Run the following command:

`python task2_security.py`

## Expected Result
- Read S3 Object: ALLOWED
- List S3 Bucket: ALLOWED
- Delete S3 Object: DENIED
- Upload S3 Object: DENIED

## Conclusion
Successfully implemented a Python-based AWS IAM security policy simulator and demonstrated the principle of least privilege.

**Note:** This is a local simulation, not an actual AWS IAM deployment.
